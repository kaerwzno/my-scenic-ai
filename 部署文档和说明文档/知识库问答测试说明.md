# 知识库问答测试说明

本文说明如何测试管理端“图谱问答测试”页面，以及如何通过 API 进行程序化批量测试。

## 重要说明：测试请使用可执行文件目录

知识库问答和图谱增强问答依赖已构建好的本地知识图谱、LightRAG 数据、向量库、数据库和模型文件。运行或测试时请使用：

```text
提交材料\可执行文件\灵山AI导游系统
```

不要从 `提交材料\源代码` 目录启动后端或管理端。`源代码` 目录只用于代码审查，未包含 `backend\lightrag_data`、`backend\chroma_db`、`backend\models`、`backend\db.sqlite3` 等运行资产，直接使用会影响知识库问答测试结果。

## 1. 测试入口

启动项目服务后，浏览器打开管理端：

```text
http://127.0.0.1:5173
```

登录后，在左侧导航栏点击：

```text
图谱问答测试
```

该页面用于测试：

- 本地景区知识库是否可用。
- 知识图谱是否能命中相关实体。
- 问答结果是否有图谱证据链。
- 大模型是否能基于证据生成自然回答。
- 响应是否稳定、及时。

## 2. 测试前检查

测试前建议先确认以下地址可用。

后端健康检查：

```text
GET http://127.0.0.1:8000/api/health/
```

RAG 就绪检查：

```text
GET http://127.0.0.1:8000/api/rag/ready/
```

建议在 RAG 就绪检查返回 `ready=true` 后再开始测试。

管理端入口：

```text
http://127.0.0.1:5173
```

如果“知识图谱”页面为空，需要先在“知识库管理”页面完成文档入库，或执行《环境配置说明.md》中的 RAG/图谱初始化命令。

## 3. 页面测试方法

在“图谱问答测试”页面中：

1. 找到“评委测试问题”输入框。
2. 输入景区事实性问题。
3. 点击“图谱增强回答”。
4. 查看回答结果。
5. 查看模型信息。
6. 查看图谱实体统计，例如实体数量、关系数量。
7. 查看“图谱证据链”列表。

测试时重点观察：

- 回答是否准确。
- 回答是否来自本地景区知识库。
- 是否展示图谱证据链。
- 是否命中相关实体。
- 响应是否在合理时间内返回。
- 是否出现接口错误、空结果或长时间无响应。

## 4. 推荐测试问题

可按下列问题逐条测试：

1. 灵山大佛有多高？
2. 灵山大佛适合从哪个角度参观？
3. 九龙灌浴表演主要看点是什么？
4. 梵宫的参观重点是什么？
5. 半天时间游览灵山，推荐怎么走？
6. 3 小时精华路线应该包含哪些景点？
7. 亲子游客适合优先看哪些景点？
8. 老年游客游览灵山时路线应该怎么安排？
9. 梵宫和灵山大佛之间怎么衔接比较顺？
10. 第一次来灵山，哪些景点最有代表性？
11. 灵山景区有哪些适合讲解佛教文化的节点？
12. 如果游客只有晚上时间，适合怎么安排？

也可以使用评审专家提供的标准问题集逐条测试。

## 5. 结果判定方式

每个问题建议记录为以下三类。

正确：

回答事实正确，和景区知识库一致，能给出相关证据链。

部分正确：

回答方向正确，但细节不完整，或证据链较弱。

错误：

回答事实错误、答非所问、无证据链，或接口失败。

建议记录格式：

```text
问题：
回答摘要：
是否有证据链：
响应是否及时：
判定：正确 / 部分正确 / 错误
备注：
```

## 6. 准确率计算

如果使用标准测试集，可按如下方式计算事实性问答准确率：

```text
准确率 = 正确题数 / 总题数 × 100%
```

例如测试 20 个问题，其中 18 个判定为正确：

```text
18 / 20 × 100% = 90%
```

若将“部分正确”计入得分，建议提前说明折算方式：

```text
正确 = 1 分
部分正确 = 0.5 分
错误 = 0 分

最终得分 = 总得分 / 总题数 × 100%
```

## 7. API 问答接口

系统提供两类问答接口。

游客端智能问答接口：

```text
POST http://127.0.0.1:8000/api/chat/
POST http://127.0.0.1:8000/api/chat/message/
```

该接口用于模拟微信小程序“导游”页提问。

管理端图谱增强问答接口：

```text
POST http://127.0.0.1:8000/api/graph/qa/
```

该接口用于测试本地景区知识库、知识图谱证据链和事实性问答准确率。若评测重点是“景区事实性问答准确率”和“本地知识库命中”，建议优先使用该接口。

## 8. 游客端智能问答 API

接口地址：

```text
POST http://127.0.0.1:8000/api/chat/
```

请求头：

```text
Content-Type: application/json
```

请求体：

```json
{
  "message": "灵山大佛有多高？",
  "session_id": "api-test-session-001",
  "stream": false
}
```

字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `message` | 是 | 用户问题 |
| `content` | 否 | 等价于 `message`，兼容小程序请求格式 |
| `session_id` | 否 | 会话 ID，同一会话可保留上下文 |
| `sessionId` | 否 | 等价于 `session_id` |
| `stream` | 否 | `true` 返回 SSE 流；批量测试建议用 `false` |

正常返回示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "answer": "灵山大佛通高88米，是灵山景区的标志性景观。",
    "session_id": "api-test-session-001",
    "meta": {
      "total_ms": 1200,
      "rag_hit": true,
      "route": "hybrid"
    }
  }
}
```

重点字段：

| 字段 | 说明 |
| --- | --- |
| `data.answer` | 回答文本 |
| `data.session_id` | 会话 ID |
| `data.meta` | 检索、生成、延迟等元信息 |
| `data.meta.rag_hit` | 是否命中本地 RAG 知识 |
| `data.meta.total_ms` | 总耗时，单位毫秒 |

## 9. 图谱增强问答 API

接口地址：

```text
POST http://127.0.0.1:8000/api/graph/qa/
```

请求头：

```text
Content-Type: application/json
```

请求体：

```json
{
  "question": "灵山大佛有多高？"
}
```

字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `question` | 是 | 景区事实性问题 |

正常返回示例：

```json
{
  "answer": "根据知识图谱，灵山大佛是灵山景区核心景观，通高88米。",
  "confidence": 0.78,
  "entities": [
    {
      "id": "灵山大佛",
      "name": "灵山大佛",
      "category": "景点",
      "description": "...",
      "degree": 8,
      "score": 4.8
    }
  ],
  "evidence": [
    {
      "type": "entity",
      "source": "灵山大佛",
      "relation": "实体说明",
      "description": "..."
    }
  ],
  "llm_used": true,
  "llm_model": "qwen3.6-flash",
  "route": "graph_augmented_llm",
  "graph_stats": {
    "nodes": 120,
    "links": 260
  }
}
```

重点字段：

| 字段 | 说明 |
| --- | --- |
| `answer` | 回答文本 |
| `confidence` | 置信度估计 |
| `entities` | 命中的图谱实体 |
| `evidence` | 图谱证据链 |
| `llm_used` | 是否使用大模型基于证据润色回答 |
| `llm_model` | 使用的大模型名称 |
| `route` | 回答路径 |
| `graph_stats` | 当前图谱节点和关系数量 |

## 12. 响应延迟观察

测试时可观察：

1. 点击“图谱增强回答”后多久出现回答。
2. API 返回中的耗时。
3. 页面是否长时间卡住。
4. 是否出现接口错误。
5. 管理端“数据看板”中的平均响应延迟指标。

如果响应明显超过预期，先检查：

1. 后端是否正在首次加载模型或索引。
2. RAG 是否 ready。
3. 网络是否能访问大模型服务。
4. 本机 CPU/GPU/内存占用是否过高。

## 13. 常见问题

页面提示图谱未加载：

先打开“知识图谱”页面刷新图谱数据；如果仍为空，检查知识库是否已经入库。

接口返回“知识图谱文件尚未生成”：

说明图谱数据不存在，需要先完成知识库入库或图谱初始化。

回答没有证据链：

问题可能未命中图谱实体。可换成包含明确景点名的问题，例如“灵山大佛有多高？”

回答很慢：

检查后端日志、RAG ready 状态和大模型接口网络。

回答事实错误：

检查知识库原始资料是否包含该事实；如资料缺失，先通过“知识库管理”上传补充文档。

连接失败：

检查后端是否启动，端口是否为 `8000`。
