# 环境配置说明

本文说明项目运行环境配置。项目分为四部分：微信小程序、后端、管理前端、数字人服务。

## 重要说明：运行目录

项目运行、部署、演示和评测时，请使用：

```text
提交材料\可执行文件\灵山AI导游系统
```

不要直接使用 `提交材料\源代码` 目录运行系统。`源代码` 目录只用于代码审查，已按提交要求移除了模型权重、知识图谱数据、向量库、数据库、数字人素材等运行资产；直接从该目录启动会导致知识库问答、图谱检索或数字人服务缺少必要文件。

## 0. 基础软件

需要准备：

- uv：用于下载指定 Python 版本、创建虚拟环境和安装依赖。
- Node.js 22 LTS：用于管理前端。
- 微信开发者工具：用于运行小程序。
- FFmpeg：用于数字人音视频处理。

数字人实时服务需要 NVIDIA 显卡和可用 CUDA 环境。

Python 由 uv 按命令中的版本自动准备，不需要单独手动安装 Python。

## 1. 后端环境

后端目录：`提交材料\可执行文件\灵山AI导游系统\backend`

后端使用 Python 3.12，由 uv 自动准备：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统\backend
uv sync --python 3.12
```

配置文件已经随源码提供：

```text
backend/.env
backend/.env.example
```

初始化数据库：

```powershell
.venv\Scripts\python.exe manage.py migrate
```

如果需要重建本地 RAG 索引：

```powershell
.venv\Scripts\python.exe manage.py prepare_rag --download
.venv\Scripts\python.exe manage.py rebuild_rag_index
.venv\Scripts\python.exe manage.py prepare_rag
```

启动后端：

```powershell
.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

检查地址：

```text
http://127.0.0.1:8000/api/health/
http://127.0.0.1:8000/api/rag/ready/
```

## 3. 数字人服务环境

数字人服务目录：`提交材料\可执行文件\灵山AI导游系统\digital-human-service`

数字人服务使用 Python 3.10，由 uv 自动准备。PyTorch GPU 版需要单独处理：不要只写 `torch==2.10.0` 后就认为装好了 GPU 版，因为 `2.10.0+cpu` 和 `2.10.0+cu128` 的公共版本号都满足 `2.10.0`。在 uv 环境中以最终验证结果为准。

创建虚拟环境：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统\digital-human-service
uv venv --python 3.10
```

先安装 GPU 版 PyTorch。推荐使用官方 CUDA wheel 的明确 URL，避免被解析成 CPU 版：

```powershell
uv pip install "https://download.pytorch.org/whl/cu128/torch-2.10.0%2Bcu128-cp310-cp310-win_amd64.whl"
```

如果需要安装配套包，再安装对应 CUDA 源中的 torchvision/torchaudio：

```powershell
uv pip install torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

验证 PyTorch 必须看到 `+cu128` 和 `True`：

```powershell
.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NO CUDA')"
```

正确示例：

```text
2.10.0+cu128
12.8
True
NVIDIA GeForce RTX 3050 Laptop GPU
```

如果看到 `2.10.0+cpu` 或 `False`，说明数字人环境不能使用 GPU，需要卸载后重新安装 CUDA wheel：

```powershell
uv pip uninstall torch torchvision torchaudio
uv pip install "https://download.pytorch.org/whl/cu128/torch-2.10.0%2Bcu128-cp310-cp310-win_amd64.whl"
```

安装数字人其他依赖：

```powershell
uv pip install -r requirements.txt
```

启动数字人服务：

```powershell
.venv\Scripts\python.exe app.py --listenport 8010
```

访问地址：

```text
http://127.0.0.1:8010/dashboard.html
```

## 4. 微信小程序环境

小程序不需要 uv，也不需要 npm。使用微信开发者工具打开：

```text
提交材料\可执行文件\灵山AI导游系统\miniprogram
```

本地调试时，在微信开发者工具中勾选：

```text
不校验合法域名、web-view、TLS 版本以及 HTTPS 证书
```

小程序访问后端地址在：

```text
miniprogram/config/env.ts
```

当前默认：

```text
http://127.0.0.1:8000
```

## 5. 推荐启动顺序

先启动后端：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统\backend
.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000 --noreload
```

再启动管理前端：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统\admin-frontend
npm run dev
```

再启动数字人服务：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统\digital-human-service
.venv\Scripts\python.exe app.py --listenport 8010
```

最后用微信开发者工具打开 `提交材料\可执行文件\灵山AI导游系统\miniprogram` 目录并编译小程序。

也可以在可执行项目根目录运行：

```powershell
cd 提交材料\可执行文件\灵山AI导游系统
一键配置并启动.bat
```

该脚本会自动配置后端、管理前端和数字人服务环境，并启动三个服务。数字人 PyTorch 会检查是否为可用 GPU 版；如果检测到 CPU 版，会重新安装指定 CUDA wheel。
