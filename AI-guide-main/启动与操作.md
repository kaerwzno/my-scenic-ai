# 启动与操作

一句话原理：**Fay 是大脑和知识库，AI-guide 是脸和嘴。**
先起 Fay（它自己会把知识库插件一起拉起来），再起前端。

---

## 第 0 步：先确认没有残留进程

关掉终端窗口**不等于**停掉服务，进程可能还在后台跑。
不确定就跑这一句看看：

```powershell
foreach ($p in 5000,10002,5010,3000,8080) {
  if (Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue) {
    "$p 还在跑"
  } else { "$p 已停" }
}
```

如果还有"在跑"，先彻底停掉（**注意：这会杀掉 Fay、知识库插件和前端**）：

```powershell
# 停 Fay 和它拉起来的所有知识库插件
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -match 'Fay-main' -or $_.CommandLine -match '重构数字人\\plugins' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force -ErrorAction SilentlyContinue }

# 停前端
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'AI-guide-main' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force -ErrorAction SilentlyContinue }
```

## 第 1 步：起 Fay（一个终端窗口，别关）

```powershell
cd D:\PROJECT\scenic_ai\重构数字人\Fay-main
& 'D:\PROJECT\scenic_ai\重构数字人\Fay-main\.venv\Scripts\python.exe' main.py start
```

**必须用 `main.py start`**，不要用 `fay_booter.py`（那个会循环导入报错）。

启动后 Fay 会自己把四个知识库插件拉起来，你不用管：
`kb-lingshan`、`kb-nianhuawan`、`kb-graph`、`fay_player_knowledge`。

看到 5000 / 10002 / 5010 三个端口起来就算好。

---

## 第 2 步：验一下知识库通不通（另开一个窗口）

```powershell
cd D:\PROJECT\scenic_ai\重构数字人\AI-guide-main
node scripts\fay-e2e-test.mjs --direct "五印坛城在哪"
```

`--direct` 是直连 Fay、不经过前端，所以这一步能在起前端**之前**做。

看到结尾这两行就是通了：

```
文字分片 5 段，音频 5 段
✅ 收到文字回答
✅ 收到音频
```

---

## 第 3 步：起前端（再开一个窗口，也别关）

```powershell
cd D:\PROJECT\scenic_ai\重构数字人\AI-guide-main
npm run dev
```

看到 `- Local: http://localhost:3000` 就好了。

> 第一次访问每个页面会当场编译，白屏 10～30 秒是正常的。
> 另外会看到一句 `[qa/avatars] 数据库不可用，改用内置预设` —— 这是**正常的**，
> 说明本机没连 Postgres，形象用的是作者内置的那 22 个。

---

## 第 4 步：打开用

浏览器地址栏输入：

```
http://127.0.0.1:3000/qa
```

操作：

- 在下面输入框打字，回车（或点发送）
- 数字人会说 + 气泡出字，口型跟着语音走
- 右上角三个按钮：**换背景 / 换形象 / 换音色**

想确认连上了，按 F12 看控制台，应该有：

```
[Fay] ✓ 已连上 ws://127.0.0.1:10002
```

---

## 第 5 步：关掉

每个终端窗口里按 `Ctrl+C`。如果窗口已经关了但进程还在，回到第 0 步的清理命令。

## 出问题看这里

| 现象 | 原因 |
|---|---|
| 回复"数字人服务没在跑（Fay 未启动）" | Fay 没起，回第 1 步 |
| 有字没有声音、嘴不动 | 浏览器要求先和页面交互过一次才允许出声；点一下页面再发 |
| 两个声音在打架 / 回答重复出现 | 别的 Fay 客户端也在用同一个用户名。别同时开 Fay 控制台页面、mate-human 的 8080 页面 |
| 3000 打不开 | 上一次的 `npm run dev` 没停干净，或被挤到了 3001 端口 |
| 接口一直转圈 | Fay 在预热知识库（第一次检索要加载模型），等一会儿 |

## 现在这套的链路（方便对代码）

```
浏览器 /qa  ──POST──▶  /api/qa/chat  ──form-data──▶  Fay /api/send
    ▲                                                      │
    │                                          知识库检索 → 模型生成 → TTS
    │                                                      │
    └──────  WebSocket ws://127.0.0.1:10002  ◀────────────┘
              Key=text  → 拼进气泡
              Key=audio → 喂给数字人，口型跟着振幅走
```

对应文件：

- `src/app/api/qa/chat/route.ts` —— 转发给 Fay
- `src/lib/fay/client.ts` —— 收 Fay 的 WebSocket
- `src/components/screens/QAScreen.tsx` —— 气泡 + 喂音频
- `scripts/fay-e2e-test.mjs` —— 一行命令验证整条链路
