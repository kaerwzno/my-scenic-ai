# scripts/

## proactive_watchdog.py —— 时间看门狗

**它是什么**：一个**真实的事件源**。持续观察 Fay 里真实的对话数据
（消息时间戳、消息长度），条件满足时推一个 observation，让灵灵主动开口。

**为什么不算"预制"**：事件来自**真实观察到的状态**，不是念稿子。
唯一人工设定的是阈值（多少分钟算久）——那是产品参数，不是内容。

**只用标准库**，任何 Python 3.8+ 都能跑，不需要装依赖。

---

## 运行

```powershell
cd D:\PROJECT\scenic_ai\重构数字人\scripts

# 安全测试：只打印不发送，绝不会打扰数字人
python proactive_watchdog.py --once --dry-run --verbose

# 正式运行（会真的让灵灵主动说话）
python proactive_watchdog.py --verbose

# 只跑一轮就退出（调试用）
python proactive_watchdog.py --once
```

| 参数 | 作用 |
|---|---|
| `--once` | 只跑一轮 |
| `--dry-run` | 只打印不发送 |
| `--verbose` / `-v` | 打印每轮观察到的真实数据，以及"为什么没触发" |
| `--config <路径>` | 指定配置文件 |

## 三条规则怎么测（★ 实用）

配置在 `watchdog.config.json`，改配置不用改代码。

### B · 已在景区游览超过 N 分钟

- **配置**：`rules.B_long_stay.after_minutes`（默认 30）
- **怎么触发**：只要你和灵灵聊过一段，它就会算"游览时长"
- **不想触发**：把 `after_minutes` 调成 999

### C · 距闭园不足 N 分钟

- **配置**：`park_close_time`（默认 `17:30`）+ `rules.C_closing_soon.before_minutes`（默认 30）
- **怎么触发**：**把 `park_close_time` 改成"当前时间 + 20 分钟"**，比如现在是 20:10，就改成 `"20:30"`
- **注意**：如果闭园时间已经过去（算出负数），规则**不会**触发——这是有意的，避免闭园后还提醒

### D · 用户最近 N 次回复都很短

- **配置**：`rules.D_short_replies.max_chars`（默认 4）、`count`（默认 2）
- **怎么触发**：在 Fay 里连续说两句短的，比如「嗯」「哦」
- **注意**：这条**不受"用户刚说话就不打扰"限制**——因为它本来就是"用户刚说完才该关心"

## 防打扰机制

| 机制 | 配置项 | 说明 |
|---|---|---|
| 全局冷却 | `global_cooldown_sec` | 主动说过一句后，多久内不再主动（默认 300 秒） |
| 单规则冷却 | `rules.*.cooldown_sec` | 同一条规则触发后，多久内不再重复 |
| 安静期 | `quiet_after_user_sec` | 用户刚说过话时，B/C 先不打扰（默认 60 秒） |

## 优先级（多条规则同时命中时谁先说）

| 规则 | priority | 为什么 |
|---|---|---|
| `C_closing_soon` | **100** | 快闭园最紧急，说晚了就没用了 |
| `D_short_replies` | **60** | 用户刚说完话，时效性强 |
| `B_long_stay` | **20** | "逛久了"任何时候说都行 |

**数值越大越先说。** 每轮只发优先级最高的那一条，
被压住的规则会打印出来，方便看清判断过程。

> 没有这个机制时会出现"C 和 D 明明满足了却永远不触发"——
> 因为代码顺序里 B 排在前面，被永远选中。这是实测踩过的坑。

## 已实现的"真"，和有意的"近似"

| 项 | 状态 |
|---|---|
| 游览时长 | ⚠️ **近似**——没有真实入园时间，用"最后一次长静默之后的第一条消息"推算（`session_gap_hours`） |
| 距闭园时间 | ✅ 真实（本地时钟 + 配置的闭园时间） |
| 用户回复长度 | ✅ 真实（读的是真实消息内容） |
| 消息时间戳 | ✅ 真实（Fay 数据库里的原始时间） |

**"游览时长"是唯一近似的地方**，等小程序接入后应换成真实事件（用户点"开始导览"）。
详见 `../docs/decisions.md` 的 D3。
